## 1.0.0

This release supports the EMS manuscript on front-aware PINNs for CO2--brine displacement fronts. The reproducibility boundary is code and configuration inspection plus no-large-assets validation; full numerical reproduction requires the separately deposited tensors, checkpoints, processed data and simulator outputs identified in the associated Zenodo records.
